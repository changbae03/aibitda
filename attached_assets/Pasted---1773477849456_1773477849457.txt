## [SECTION 1] 핵심 가정 테이블

아래 항목을 Bear / Base / Bull 3가지 시나리오로 반드시 수치로 채우세요.
없는 데이터는 아래 기준으로 추정하세요:
- CAPEX: 영업현금흐름의 65~75% (삼성전자 과거 평균 적용)
- 감가상각: EBITDA - 영업이익으로 역산
- 운전자본 변동: 매출의 2~3%
- Unlevered Beta: 반도체/하드웨어 업종 평균 1.1~1.3 적용
- ERP(한국): 6.0~6.5% (Damodaran 추정치)

|-----------|------|------|------|
| 시나리오 배경 (한 문장) | | | |

| 매출 CAGR 6~10년 | | | |

| 유효세율 | | | |
| Sales-to-Capital Ratio | | | |
| WACC | | | |
| Terminal Growth Rate | | | |

WACC 산출 근거를 아래 형식으로 명시하세요:
- 무위험수익률: 한국 10년 국채 수익률 (추정 XX%)
- Relevered Beta: Unlevered Beta × (1 + (1-세율) × D/E)
- ERP: Damodaran 한국 추정치 XX%
- Cost of Equity = 무위험수익률 + Beta × ERP
- 세후 Cost of Debt = 이자비용/총부채 × (1-세율)
- WACC = CoE × E비중 + CoD × D비중

## [SECTION 2] DCF 10년 FCFF 추정 (Base Case)

아래 공식을 적용하세요:
- NOPAT = 영업이익 × (1 - 유효세율)
- 재투자 = 매출증분 / Sales-to-Capital Ratio
- FCFF = NOPAT - 재투자
- Terminal Value = FCFF(10년) × (1 + g) / (WACC - g)

| 3 | | | | | | |

| 6~10 합계 | | | | | | |
| Terminal Value PV | | | | | | |

주주가치 = 기업가치 + 순현금(현금 - 부채)
주당 내재가치 = 주주가치 / 발행주식수
